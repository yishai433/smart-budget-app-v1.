# תקציב חכם — דמו React Native (Expo)

תיקיית ניסוי בתוך הריפו. היא **לא** משפיעה על האתר הקיים ולא על הפריסה שלו.

דמו ויזואלי בלבד: אין התחברות ואין Firebase. הנתונים הם דוגמה (`src/data/mock.js`),
כדי שתוכל לראות איך האפליקציה מרגישה על הטלפון לפני שנחליט להמיר הכול.

## מה יש
- ארבע לשוניות: תקציב, דוחות, קניות, הגדרות — בעברית ומימין לשמאל.
- **מסך תקציב מלא**: כרטיס "הוצאנו החודש" עם טבעת התקדמות, תחזית סוף חודש, שורת KPI
  (חיסכון / הוצאות / הכנסות), פירוק קטגוריות עם ברים, ורשימת תנועות.
- דוחות: ברים לפי קטגוריה. קניות: רשימה עם סימון. הגדרות: בחירת שפה/מראה/מטבע.
- אותה פלטת צבעים כמו האתר, כולל מצב כהה (לפי הגדרת הטלפון).

## הרצה (ב-Expo Go שכבר מותקן אצלך)
```
cd expo-app
npm install
npx expo start --tunnel
```
סורקים את ה-QR עם Expo Go. אם הטקסט לא יוצא מימין לשמאל בפתיחה הראשונה, סוגרים
את האפליקציה ב-Expo Go ופותחים שוב פעם אחת.

## מה אין (בכוונה, זה דמו)
התחברות, נתונים אמיתיים, סריקת ברקוד והשוואת סל. נוסיף אותם כשנחליט להמיר באמת.
